# Модуль відмінювання українських слів

Реалізація алгоритму відмінювання українських ПІБ, посад та місяців по 7 відмінках на платформі 1С:Підприємство 8.3.  
Переписано з Turbo Delphi (бібліотека `Padeg_ua.dll`, автор Тарасенков В.М.).

## Стать (`Пол`)

| Значення     | Трактування                        |
| ------------ | ---------------------------------- |
| `"М"`, `"Ч"` | Чоловічий рід                      |
| `"Ж"`        | Жіночий рід                        |
| `""`         | Автоматичне визначення по-батькові |

## Публічний API

### `ПолучитьФИО(Фамилия, Имя, Отчество, Пол, НомерПадежа)`

Відмінює ПІБ, передані окремими частинами.  
Еквівалент `GetFIOPadeg` з `Padeg_ua.dll`.

| Параметр      | Тип    | Опис                              |
| ------------- | ------ | --------------------------------- |
| `Фамилия`     | Строка | Прізвище                          |
| `Имя`         | Строка | Ім'я                              |
| `Отчество`    | Строка | По-батькові                       |
| `Пол`         | Строка | Стать (`"М"/"Ч"`, `"Ж"` або `""`) |
| `НомерПадежа` | Число  | Відмінок 1..7                     |

**Повертає:** `Строка` — повне ПІБ у заданому відмінку.

---

### `ПолучитьФИОСтрокой(ФИО, Пол, НомерПадежа)`

Відмінює ПІБ, передане одним рядком (прізвище ім'я по-батькові через пробіл).  
Еквівалент `GetFIOPadegFS` з `Padeg_ua.dll`.

| Параметр      | Тип    | Опис                   |
| ------------- | ------ | ---------------------- |
| `ФИО`         | Строка | Повне ПІБ через пробіл |
| `Пол`         | Строка | Стать або `""` (авто)  |
| `НомерПадежа` | Число  | Відмінок 1..7          |

**Повертає:** `Строка` — ПІБ у заданому відмінку.

---

### `ПолучитьФИОАвтоПол(ФИО, НомерПадежа)`

Відмінює ПІБ з автоматичним визначенням статі по-батькові.  
Якщо по-батькові відсутнє або не розпізнане — повертає рядок без змін.

| Параметр      | Тип    | Опис                   |
| ------------- | ------ | ---------------------- |
| `ФИО`         | Строка | Повне ПІБ через пробіл |
| `НомерПадежа` | Число  | Відмінок 1..7          |

**Повертає:** `Строка` — ПІБ у заданому відмінку.

---

### `ПолучитьИО(Имя, Фамилия, Пол, НомерПадежа)`

Відмінює ім'я та прізвище (без по-батькові).  
Еквівалент `GetIFPadeg` з `Padeg_ua.dll`.

| Параметр      | Тип    | Опис          |
| ------------- | ------ | ------------- |
| `Имя`         | Строка | Ім'я          |
| `Фамилия`     | Строка | Прізвище      |
| `Пол`         | Строка | Стать         |
| `НомерПадежа` | Число  | Відмінок 1..7 |

**Повертає:** `Строка` — ім'я та прізвище у заданому відмінку.

---

### `ОпределитьПол(Отчество)`

Визначає стать особи по-батькові.  
Аналіз закінчення: `-ович`/`-йович` = чоловічий, `-івна`/`-овна` = жіночий.  
Еквівалент `GetSex` з `Padeg_ua.dll`.

| Параметр   | Тип    | Опис        |
| ---------- | ------ | ----------- |
| `Отчество` | Строка | По-батькові |

**Повертає:** `Число` — `1` (чоловічий), `0` (жіночий), `-1` (невизначено).

---

### `РазделитьФИО(ФИО, Фамилия, Имя, Отчество)`

Розбиває рядок ПІБ на складові: прізвище, ім'я, по-батькові.  
Порядок слів: Прізвище Ім'я По-батькові.  
Еквівалент `SeparateFIO` з `Padeg_ua.dll`.

| Параметр   | Тип    | Напрям | Опис        |
| ---------- | ------ | ------ | ----------- |
| `ФИО`      | Строка | вхід   | Повне ПІБ   |
| `Фамилия`  | Строка | вихід  | Прізвище    |
| `Имя`      | Строка | вихід  | Ім'я        |
| `Отчество` | Строка | вихід  | По-батькові |

---

### `ПолучитьДолжность(Должность, НомерПадежа)`

Відмінює назву посади по заданому відмінку.  
Еквівалент `GetAppointmentPadeg` з `Padeg_ua.dll`.

**Правило відмінювання:**

- Якщо перше слово — **іменник**: відмінюється тільки воно. Решта — без змін.
- Якщо перше слово — **прикметник** (закінчення `-ий`/`-ій`): відмінюється перше + друге слово. Решта — без змін.

| Вхід                         | Родовий                        |
| ---------------------------- | ------------------------------ |
| `начальник відділу кадрів`   | `начальника відділу кадрів`    |
| `головний бухгалтер`         | `головного бухгалтера`         |
| `старший менеджер з продажу` | `старшого менеджера з продажу` |

| Параметр      | Тип    | Опис          |
| ------------- | ------ | ------------- |
| `Должность`   | Строка | Назва посади  |
| `НомерПадежа` | Число  | Відмінок 1..7 |

**Повертає:** `Строка` — посада у заданому відмінку.

---

### `ПолучитьОтдел(Отдел, НомерПадежа)`

Відмінює назву відділу/підрозділу. Делегує до `ПолучитьДолжность`.  
Еквівалент `GetOfficePadeg` з `Padeg_ua.dll`.

---

### `ПолучитьПолнуюДолжность(Должность, Отдел, НомерПадежа)`

Відмінює повну посаду (назва посади + підрозділ) та об'єднує результат.  
Еквівалент `GetFullAppointmentPadeg` з `Padeg_ua.dll`.

| Параметр      | Тип    | Опис          |
| ------------- | ------ | ------------- |
| `Должность`   | Строка | Назва посади  |
| `Отдел`       | Строка | Назва відділу |
| `НомерПадежа` | Число  | Відмінок 1..7 |

**Повертає:** `Строка` — повна посада у заданому відмінку.

---

### `ПолучитьМесяц(НаименованиеМесяца, Падеж)`

Повертає назву українського місяця у заданому відмінку.  
Пошук по словнику без урахування регістру.  
При невідомій назві повертає вхідний рядок без змін.

| Параметр             | Тип    | Опис                                            |
| -------------------- | ------ | ----------------------------------------------- |
| `НаименованиеМесяца` | Строка | Назва місяця (наприклад, `"січень"`, `"Лютий"`) |
| `Падеж`              | Число  | Відмінок 1..7                                   |

**Повертає:** `Строка` — назва місяця у заданому відмінку.

---

### `ПолучитьМесяцПоДате(Дата, Падеж)`

Повертає назву місяця переданої дати у заданому відмінку.

| Параметр | Тип   | Опис          |
| -------- | ----- | ------------- |
| `Дата`   | Дата  | Довільна дата |
| `Падеж`  | Число | Відмінок 1..7 |

**Повертає:** `Строка` — назва місяця у заданому відмінку.

## Внутрішня архітектура

```
ПолучитьФИОСтрокой / ПолучитьФИОАвтоПол
    └─► РазделитьФИО          (розбивка рядка ПІБ)
    └─► ПолучитьФИО
            └─► _ПолучитьЧасть              (для кожної частини: прізвище, ім'я, по-батькові)
                    └─► _ПолучитьСлово      (ядро алгоритму: визначення відміни + закінчення)
                            ├─► _НормализоватьСлово
                            ├─► _ОпределитьОкончание
                            ├─► _НайтиВСловаре → _ПолучитьСловарь
                            ├─► _ЯвляетсяГласной / _ЯвляетсяСогласной
                            ├─► _ЯвляетсяШиплячей / _ЯвляетсяМягкой
                            └─► _СохранитьРегистр

ПолучитьДолжность
    └─► _ПолучитьФрагментДолжности
            └─► _НайтиВСловаре → _ПолучитьСловарь
            └─► _ПолучитьСлово

ПолучитьМесяц / ПолучитьМесяцПоДате
    └─► ТаблицяВідмінюванняУкраїнськихМісяців
    └─► ФормаМісяцяЗаВідмінком
```

### Алгоритм `_ПолучитьСлово` (кроки)

1. Нормалізація (заміна латинських символів-двійників на кирилицю)
2. Пропуск однолітерних слів
3. Пропуск абревіатур (слово повністю у верхньому регістрі)
4. Обробка порядкових числівників (`1-й`, `2-а`)
5. Обробка складних слів через дефіс (рекурсивно для кожної частини)
6. Пошук у словнику незмінних слів
7. Визначення закінчення та основи
8. Визначення роду (з параметра → зі словника → автоматично за закінченням)
9. Спеціальні правила: слова на `-ець`, прізвища на `-ова/-ева`
10. Відмінювання **прикметників** (`-ий`/`-ій`, тверда та м'яка група, ч./ж. рід)
11. Відмінювання **іменників** (I, II, III відміна)
12. Відновлення оригінального регістру

## Вбудований словник (`_ПолучитьСловарь`)

Словник зберігається у форматі INI-рядка і парситься при кожному виклику.  
Структура: `Соответствие` (назва секції → `Соответствие` (слово → `Истина`)).

| Секція                             | Призначення                                                     |
| ---------------------------------- | --------------------------------------------------------------- |
| `Незмінні`                         | Слова, що не відмінюються: авто, бюро, кіно, метро тощо         |
| `ЧоловічіІмена`                    | Чоловічі імена на `-а`/`-я` (Микола, Ілля, Сава, Лука)          |
| `ЖіночіІмена`                      | Жіночі імена на приголосну (Любов, Нінель)                      |
| `Відмінювання2ВключаєЗакінченняНА` | Імена, де Родовий закінчується на `-ни` (Ніна→Ніни, Зіна→Зіни)  |
| `НезмінніЧастиниСлів`              | Незмінні префікси у складних словах (біла, нова, дніпро)        |
| `НезмінніСловаДляПосад`            | Прийменники та сполучники у посадах (за, із, до, при, з, у, в…) |
| `Виключення`                       | Слова з особливим відмінюванням (господь)                       |
| `ПершаЛітераЗВеликої`              | Слова, де регістр першої літери зберігається (Рівне, Луцьк)     |

## Особливі правила відмінювання

### Прізвища

| Тип                            | Правило                                 | Приклад                  |
| ------------------------------ | --------------------------------------- | ------------------------ |
| На `-ова`/`-ева`/`-єва` (жін.) | Прикметниковий тип (повне відмінювання) | Картавцева → Картавцевої |
| На `-о`/`-ко`/`-єнко`          | Відмінюються однаково для обох статей   | Іваненко → Іваненка      |
| Жіночі на приголосну           | Незмінні у всіх відмінках               | Коваль → Коваль          |

### По-батькові

У Давальному, Місцевому та Кличному по-батькові приймає закінчення `-у` замість `-ові`/`-еві`:

| Тип слова   | Давальний   | Кличний     |
| ----------- | ----------- | ----------- |
| Ім'я        | Сергієві    | Сергію      |
| По-батькові | Сергійовичу | Сергійовичу |

### Слова на `-ець` (біглий голосний)

| Відмінок  | Форма     |
| --------- | --------- |
| Називний  | фахівець  |
| Родовий   | фахівця   |
| Давальний | фахівцеві |
| Знахідний | фахівця   |
| Орудний   | фахівцем  |
| Місцевий  | фахівцеві |
| Кличний   | фахівцю   |

### Імена на `-ія` (Наталія, Марія, Надія)

| Відмінок  | Форма    |
| --------- | -------- |
| Називний  | Наталія  |
| Родовий   | Наталії  |
| Давальний | Наталії  |
| Знахідний | Наталію  |
| Орудний   | Наталією |
| Місцевий  | Наталії  |
| Кличний   | Наталіє  |

## Нормалізація латинських символів

Перед відмінюванням слово проходить автоматичну заміну символів, що візуально схожі на кирилицю (можуть потрапити з буфера обміну або OCR):

`i→і`, `I→І`, `o→о`, `O→О`, `p→р`, `a→а`, `e→е`, `x→х`, `c→с`, `B→В`, `M→М`, `H→Н`, `K→К`, `T→Т`, `y→у` та інші.

## Приклади використання

```1c
// Відмінювання ПІБ — Родовий відмінок
Результат = ПолучитьФИОСтрокой("Іваненко Петро Миколайович", "", 2);
// → "Іваненка Петра Миколайовича"

// Автовизначення статі
Результат = ПолучитьФИОАвтоПол("Коваленко Ольга Василівна", 3);
// → "Коваленко Ользі Василівні"

// Відмінювання посади — Давальний відмінок
Результат = ПолучитьДолжность("головний бухгалтер", 3);
// → "головному бухгалтеру"

// Відмінювання місяця
Результат = ПолучитьМесяцПоДате(ТекущаяДата(), 2);
// → "травня" (для травня)

// Визначення статі
Пол = ОпределитьПол("Миколаївна"); // → 0 (жіночий)
Пол = ОпределитьПол("Петрович");   // → 1 (чоловічий)
```
